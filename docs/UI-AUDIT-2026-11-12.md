## Temuan per tingkat keparahan & perbaikannya

### P0 — Halaman simulasi tidak bisa dipakai di HP
**Bukti:** tangkapan layar `m-bandul.png` (sebelum) — kanvas tertqueeze ~140px, tombol "Reset Simulasi" terpotong, bilah kontrol keluar viewport.

**Perbaikan** (`bandul/ExperimentView.tsx`, `millikan/ExperimentView.tsx`):
- Area kanvas & panel ditumpuk vertikal di bawah `lg` (`flex-col lg:flex-row`); kanvas dapat tinggi tetap `44–46vh` (min 280–300px), panel jadi area penuh di bawahnya (bukan lebar tetap 320px).
- Panel samping diganti dari animasi lebar Framer Motion ke lebar berbasis kelas → tidak ada lagi lebar tetap yang memaksa kanvas menyusut.
- Bilah kontrol melayang: membungkus ke dua baris di layar sempit, label "Reset Simulasi" jadi ikon saja (< sm) dengan `sr-only` untuk pembaca layar.
- Readout "T (teoritis)" digambar ulang ke **kanan atas** kanvas (sebelumnya kanan bawah → bertabrakan dengan bilah kontrol).
- Indikator langkah ringkas "3 / Pengukuran" ditambahkan di header untuk mobile (sebelumnya nav langkah hanya tampil di `md+`).

### P1 — Tombol putih di atas putih (tak terlihat)
**Bukti:** kontras terukur 1.0:1 pada CTA "Pelajari Pendekatan Kami" (`FeaturesSection.tsx`) — `variant="outline"` memberi `bg-background` (putih) sementara teksnya `text-white`.

**Perbaikan:** `bg-transparent border-white/25 text-white hover:bg-white/10`.

### P1 — Ruang kosong besar di hero mobile
**Bukti:** `m-beranda.png` (sebelum) — ~165px kosong sebelum badge, CTA berada di bawah lipatan layar.

**Perbaikan:** `min-h-screen` hanya di `lg`, padding & ukuran heading/lead disetel per breakpoint (`text-[2.1rem] sm:text-5xl`, `text-base sm:text-lg`).

### P1 — Error runtime di kanvas Millikan
**Bukti:** `pageerror: createRadialGradient … r1 provided is negative` (mobile).

**Akar:** kanvas belum berukuran pada frame pertama → `chW = 0` → `plateW = -10` → radius gradien negatif.

**Perbaikan:** guard `if (W < 40 || H < 40) return;` + clamp `plateW = Math.max(12, chW - 10)`.

### P1 — Teks 8–10px di seluruh aplikasi
327 kelas `text-[8px]`/`[9px]`/`[10px]` dinormalisasi ke `text-[11px]` (31 file). Label kecil kini terbaca tanpa mengubah struktur layout.

### P1 — Kontras di atas permukaan terang
- `text-success` (emerald-500, 2.5:1) → `text-emerald-700` (4.8:1) pada permukaan terang: label langkah, nilai galat, "R²", status pretest.
- `text-amber-500` (ikon & label) → `text-amber-600/700`.
- `text-slate-400/500` → lebih gelap sesuai latar (terang/gelap dibedakan, bukan diganti global).

### P2 — Struktur heading & nama aksesibel
- `h1` (`sr-only`) ditambahkan di wrapper experiment/analysis per modul + halaman login.
- Slider keyakinan Millikan & slider kandidat satuan diberi `aria-label`.

### P2 — Target sentuh
- Link breadcrumb, link footer, tombol collapse panel, dan pembungkus `<a>` CTA diberi padding agar ≥24px (WCAG 2.5.8) tanpa mengubah jarak visual (`py-1 -my-1`).
- Slider keyakinan: elemen input setinggi 24px dengan jalur tipis digambar terpisah (sebelumnya area sentuh hanya 6px).

### P3 — Polem design (craft floor)
- Teks gradien pada judul hero → warna solid (`text-accent-cobalt` / `text-teal`).
- Badge "eyebrow" dipindah dari atas judul ke bawahnya (kicker di atas heading adalah pola yang dihindari).
- Separator dekoratif "/" diberi `aria-hidden="true"`.

## Metodologi & batasan (jujur)

- **Audit kontras memakai kanvas 2D untuk normalisasi warna** (`lab()`, `oklch()`, `rgba()`) lalu menghitung rasio WCAG; elemen berlatar gradien **dilewati** (rasio tidak bisa dihitung tekstual) — ini sumber false-positive paling sering, sudah diminimalkan tapi tidak nol.
- Elemen **disabled** (tombol nonaktif) dikecualikan dari aturan kontras sesuai WCAG 1.4.3.
- Skrip mengukur **viewport teremulasi**, bukan perangkat fisik: gestur sentuh (drag slider 3D, pinch) belum diuji pada perangkat nyata.
- Audit ini **tidak** menilai kualitas instructional/pedagogis — itu domain uji manusia (G-2).
- Skor "0 error konsol" berlaku untuk halaman yang dimuat tanpa interaksi; interaksi panjang (mis. menjalankan simulasi 60 detik) tidak diotomatisasi penuh.
