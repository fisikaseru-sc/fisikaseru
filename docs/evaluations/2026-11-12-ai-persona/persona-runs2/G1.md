## TEMUAN

### 1. Estimasi muatan elementer e menyimpang 7.80% — GAGAL kriteria H3 <3%
**Severity: [CRITICAL]**

Nilai e yang ditampilkan ≈ 1.727×10⁻¹⁹ C vs nilai NIST 1.602×10⁻¹⁹ C → Δ = (1.727−1.602)/1.602 × 100% = 7.80%. Kriteria protokol H3 eksplisit menyebut "Δ < 3% (dengan koreksi Cunningham)". Selisih 7.80% adalah ~2.6× batas toleransi. Untuk konteks: penyimpangan >5% pada konstanta fundamental sudah cukup membuat siswa mendapatkan gambaran salah tentang orde besaran dan ketelitian eksperimen Millikan historis (Millikan sendiri mengklaim ~0.5%). Tanpa koreksi Cunningham pada droplet beradius kecil, bias sistematik memang menggeser e ke atas — persis pola yang teramati (1.727 > 1.602). Jika koreksi Cunningham tidak diaktifkan atau salah implementasi, ini menjelaskan arah bias.

**BUKTI:** "estimasi e yang ditampilkan ≈ 1.727×10⁻¹⁹ C, Δ vs NIST (1.602×10⁻¹⁹) = 7.80% — GAGAL kriteria protokol H3 'Δ < 3% (dengan koreksi Cunningham)'."

**REKOMENDASI:** Verifikasi implementasi koreksi Cunningham: faktor koreksi (1 + A·λ/r) harus aktif untuk droplet dengan radius mendekati mean free path udara (~68 nm pada STP). Hitung ulang radius droplet dari hukum Stokes dan terapkan koreksi sebelum ekstraksi e. Targetkan Δ < 1.5% agar ada margin. Sertakan flag di UI: "Koreksi Cunningham: AKTIF" sehingga siswa dan penguji dapat memverifikasi.

### 2. Jalur kandidat default Millikan (q_terkecil = 3.13) BUNTU secara pedagogis
**Severity: [HIGH]**

Tahap 3 "Cari Pola" mengarahkan siswa ke kandidat default = muatan terkecil (3.13×10⁻¹⁹ C). Namun 3.13 ternyata n=2 (bukan n=1), sehingga deviasi 0.22 dan pesan "Titik-titik masih tersebar" muncul tanpa penjelasan mengapa. Siswa harus menebak sendiri untuk beralih ke kandidat ~1.60. Ini bukan "discovery terbimbing" melainkan "trial-and-error tanpa scaffold". Bagi siswa yang tidak terbiasa, ini bisa berakhir kebuntuan total. Secara pedagogis, hipotesis "q terkecil = satuan dasar" adalah heuristik yang valid secara intuitif, tetapi di sini data sengaja (atau tak sengaja) tidak memuat droplet n=1, sehingga heuristik itu dijebak.

**BUKTI:** "kandidat default = q terkecil (3.13) → deviasi 0.22, pesan 'Titik-titik masih tersebar' — jalur pertama BUNTU karena 3.13 ternyata 2 satuan (bukan 1). Siswa HARUS iterasi sendiri ke kandidat ~1.60." Lima droplet: q = 6.62, 4.81, 6.40, 4.67, 3.13 → n = 4, 3, 4, 3, 2. Tidak ada droplet n=1.

**REKOMENDASI:** Tambahkan hint adaptif: setelah 2 percobaan gagal dengan deviasi >0.15, tampilkan petunjuk "Coba bagi nilai q dengan n yang terdeteksi — apakah ada satu nilai yang konsisten?" atau sediakan setidaknya satu droplet dengan n=1 agar jalur default menghasilkan keberhasilan. Alternatif: ubah default awal ke hasil rata-rata q/n alih-alih q_min.

### 3. Galat g bandul Bumi tidak reproducible antar ronde (1.68% vs 3.60%)
**Severity: [HIGH]**

Ronde 1: galat 3.60% (>kriteria 2%, GAGAL). Ronde 2: galat 1.68% (<2%, LULUS). Akar masalah: noise 1.5% relatif pada periode T membuat hasil tidak deterministik — setiap run memberi g berbeda. Untuk eksperimen kalibrasi gravitasi yang seharusnya mengilustrasikan determinisme hukum fisika, ini mengirim pesan yang salah: "kadang akurat, kadang tidak, tanpa alasan jelas." Sebagai guru, saya tidak bisa menjadikan ini acuan ujian atau laboratorium grading.

**BUKTI:** "g terukur 9.9710 m/s² vs referensi 9.8066, galat ≈ 1.68%, R² sangat tinggi → LULUS kriteria <2% (kali ini; ronde 1 dengan data lain galatnya 3.60% — noise 1.5% relatif pada T membuat hasil tidak deterministik)."

**REKOMENDASI:** Fixed-seed RNG untuk mode eksperimen (dapat di-reset per sesi siswa), atau kurangi amplitude noise T dari 1.5% ke ≤0.5%. Dokumentasikan nilai seed dan noise di metadata eksperimen agar guru dapat audit reproducibility. Sediakan mode "demo deterministik" tanpa noise untuk pengenalan konsep.

### 4. Preset non-Bumi hanya 3 titik data → galat 2.46%–4.8%, tidak cukup untuk regresi reliable
**Severity: [MEDIUM]**

Regresi linear T² vs L dengan 3 titik secara matematis always perfect fit (R²=1 secara definisi untuk 2 parameter, 3 titik), sehingga R² tidak bermakna sebagai indikator kualitas. Galat 4.8% (Bulan) dan 2.46% (Jupiter) dengan 3 titik tidak dapat dikonfirmasi atau di-refute secara statistik — tidak ada derajat bebas untuk uji goodness-of-fit. Sebagai pengajar, saya tidak bisa mengatakan pada siswa "regresi ini valid" ketika secara statistik tidak teruji.

**BUKTI:** "Preset Bulan (g=1.62 m/s²), 3 trial L=0.3/0.6/0.9: ... galat ≈ 4.8%. Preset Jupiter (g=24.79 m/s²), 3 trial: galat ≈ 2.46%. Dengan hanya 3 titik data, galat cenderung > 2%."

**REKOMENDASI:** Naikkan minimum titik data preset non-Bumi menjadi ≥5 (sama dengan Bumi). Tampilkan derajat bebas (n−2) dan interval kepercayaan ĝ di panel analisis. Jika R² ditampilkan, sertakan catatan "R² dengan 3 titik tidak diagnostik — gunakan ≥5 titik."
