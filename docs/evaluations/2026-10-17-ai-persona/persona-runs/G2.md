## 2. Ketepatan Konsep dan Notasi Fisika

### A. Modul Gerak Parabola (H1)
- **Kesesuaian Teori:** Rumus jangkauan horizontal $R = \frac{v_0^2 \sin(2\theta)}{g}$ (untuk $h_0 = 0$).
- **Perhitungan Verifikasi:**
  - $v_0 = 25\text{ m/s}, g = 9.81\text{ m/s}^2$:
    - $\theta = 30^\circ \implies R = \frac{25^2 \sin(60^\circ)}{9.81} = \frac{625 \times 0.8660}{9.81} = 55.18\text{ m}$ (Tampilan teori: $55.2\text{ m}$, Data trial: $56.0\text{ m}$).
    - $\theta = 45^\circ \implies R = \frac{25^2 \sin(90^\circ)}{9.81} = \frac{625 \times 1.0000}{9.81} = 63.71\text{ m}$ (Data trial: $63.0\text{ m}$).
    - $\theta = 60^\circ \implies R = \frac{25^2 \sin(120^\circ)}{9.81} = \frac{625 \times 0.8660}{9.81} = 55.18\text{ m}$ (Tampilan teori: $55.2\text{ m}$, Data trial: $55.6\text{ m}$).
- **Evaluasi Fisika:** Hubungan sudut komplementer ($30^\circ$ dan $60^\circ$ menghasilkan $R \approx 55.2\text{ m}$) serta puncak di $45^\circ$ terbukti akurat secara konseptual.

### B. Modul Bandul Sederhana (H2)
- **Kesesuaian Teori:** $T = 2\pi\sqrt{\frac{L}{g}} \implies T^2 = \left(\frac{4\pi^2}{g}\right)L$. Gradien regresi garis lurus $m = \frac{4\pi^2}{g} \implies g = \frac{4\pi^2}{m}$.
- **Perhitungan Verifikasi:**
  - Dari bukti observasi: Gradien $m = 3.8857\text{ s}^2/\text{m}$.
  - $g_\text{hitung} = \frac{4 \times \pi^2}{3.8857} = \frac{39.4784}{3.8857} = 10.1599\text{ m/s}^2$ (Tampilan: $10.1598\text{ m/s}^2$).
  - Terhadap $g_\text{referensi} = 9.8067\text{ m/s}^2$:
    $$\text{Galat} = \frac{|10.1598 - 9.8067|}{9.8067} \times 100\% = 3.60\%$$
- **Evaluasi Fisika:** Angka hitungan konsisten secara matematis, **tetapi gagal memenuhi kriteria protokol (target galat < 2%)**.

### C. Modul Tetes Minyak Millikan (H3)
- Notasi kesetimbangan gaya ($F_g$ gravitasi vs $F_e$ listrik) dan rumus kuat medan $E = \frac{V}{d}$ ($V = 600\text{ V}, E = 120.0\text{ kV/m} \implies d = 5.0\text{ mm}$) tepat dan sesuai konvensi laboratorium fisika modern.

## 5. Potensi Miskonsepsi yang Bisa Ditimbulkan
1. **Galat Bandul Melebihi Ekspektasi ($3.60\%$):** Siswa dapat beranggapan bahwa persamaan $T = 2\pi\sqrt{L/g}$ memiliki deviasi nyata di Bumi atau regresi linear tidak akurat, karena galat berada di atas batas toleransi praktikum virtual ($< 2\%$).
2. **Duplikasi Identitas Tetes Minyak:** Pada data observasi Millikan, label `Drop #01` muncul dua kali dengan parameter berbeda ($r = 0.97\,\mu\text{m}$ dan $r = 0.88\,\mu\text{m}$). Siswa dapat salah mengira bahwa satu tetes yang sama mengecil secara drastis, padahal sistem merekam droplet yang berbeda.
3. **Penyederhanaan Parabola:** Untungnya modul secara eksplisit menuliskan batas keberlakuan model ideal ($h_0 = 0$ dan tanpa hambatan udara), sehingga memitigasi miskonsepsi bahwa $45^\circ$ selalu menjadi sudut terjauh di semua kondisi nyata.

## Tiga Masalah Paling Penting

### 1. Galat Penentuan Gravitasi pada Modul Bandul Melebihi Kriteria Toleransi (3.60% > 2%)
- **Bukti Observasi:** Pada `analysis_dengan_data`: $g_\text{hitung} = 10.1598\text{ m/s}^2$ vs $g_\text{referensi} = 9.8067\text{ m/s}^2$, menghasilkan Galat = $3.60\%$.
- **Tingkat Keparahan:** **HIGH**
- **Rekomendasi:** Sesuaikan sampling algoritma pencatatan periode atau reduksi noise pengukuran pada simulasi bandul saat merekam 5 titik uji Bumi ($L = 0.2 - 1.0\text{ m}$) agar hasil estimasi regresi $g$ menghasilkan galat di bawah $2\%$, sesuai kriteria kelulusan skenario H2.

### 2. Inkonsistensi Penomoran Droplet pada Log Eksperimen Millikan
- **Bukti Observasi:** Pada `lima_tetes` dan `analysis`: Tertera dua baris dengan nama identik `Drop #01` namun jari-jari berbeda ($0.97\,\mu\text{m}$ dan $0.88\,\mu\text{m}$), diikuti `Drop #02`, `Drop #03`, dan `Drop #04`.
- **Tingkat Keparahan:** **MEDIUM**
- **Rekomendasi:** Perbaiki generator indeks ID droplet agar selalu unik (*autoincrement* berurutan: #01, #02, #03, #04, #05) saat data dicatat, untuk mencegah kebingungan interpretasi data partikel oleh siswa.

### 3. Notifikasi Tegangan Mati Belum Teramati Memblokir/Memperingatkan Rekaman Sesuai Protokol
- **Bukti Observasi:** Pada `warning_tegangan_mati`, hanya teks status kanvas yang berubah menjadi `E = 0 (Jatuh Bebas)` dan `Medan Listrik Pelat OFF (Mati)`. Peringatan teks eksplisit *"Medan listrik belum aktif..."* tidak teramati dalam data ekstrak.
- **Tingkat Keparahan:** **LOW**
- **Rekomendasi:** Pastikan ketika tombol *Rekam Observasi* ditekan saat kondisi medan OFF, sistem memunculkan umpan balik interaktif (toast/banner peringatan) yang eksplisit memandu siswa menyalakan medan listrik terlebih dahulu.
