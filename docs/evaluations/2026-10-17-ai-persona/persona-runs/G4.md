## 2. Ketepatan Konsep dan Notasi Fisika (Cek Numerik)

### A. Modul Bandul (Linearisasi $T^2$ vs $L$)
- **Formulasi:** 
  $$T \approx 2\pi\sqrt{\frac{L}{g}} \implies T^2 = \left(\frac{4\pi^2}{g}\right)L$$
- **Cek Data Nyata ($n = 5$):**
  - Gradien regresi teramati: $m = 3{,}8857\text{ s}^2/\text{m}$, $R^2 = 0{,}9997$.
  - Perhitungan $g$:
    $$g_{\text{hitung}} = \frac{4\pi^2}{m} = \frac{4 \times (3{,}14159265)^2}{3{,}8857} \approx 10{,}1598\text{ m/s}^2$$
    *(Sistem menampilkan $10{,}1598\text{ m/s}^2$ — kalkulasi matematis konsisten).*
  - Perhitungan galat relatif terhadap $g_{\text{ref}} = 9{,}8067\text{ m/s}^2$:
    $$\text{Galat} = \frac{|10{,}1598 - 9{,}8067|}{9{,}8067} \times 100\% = \frac{0{,}3531}{9{,}8067} \times 100\% \approx 3{,}60\%$$
  - **Catatan Guru:** Target protokol menetapkan galat $< 2\%$, namun hasil eksperimen riil menghasilkan galat **$3{,}60\%$**. Penyimpangan ini melebihi ambang batas toleransi akibat kombinasi simpangan awal ($\theta_0 = 10^\circ$, koreksi orde dua $\approx 1 + \theta_0^2/16 = 1{,}0019$) dan *synthetic noise* simulasi.

### B. Kasus Regresi Tunggal ($n = 1$) pada Bukti H4
- Ketika hanya ada 1 titik data ($L = 0{,}75\text{ m}, T = 1{,}721\text{ s}$), sistem menampilkan:
  - $\text{Gradien} = 0{,}0000$
  - $R^2 = 0{,}0000$
  - $g_{\text{hitung}} = 0{,}0000\text{ m/s}^2$
  - **$\text{Galat} = 0{,}00\%$** $\rightarrow$ **Cacat fatal logika matematika.** Galat dihitung $0\%$ padahal nilai ukur $0$ terhadap referensi $9{,}81$.

## 5. Potensi Miskonsepsi
1. **Regresi $n = 1$ menghasilkan "Galat 0.00%":** Siswa dapat menyimpulkan bahwa 1 kali percobaan sudah cukup dan akurat sempurna. Padahal regresi linier mensyaratkan minimal $n \ge 3$ untuk derajat kebebasan yang valid.
2. **Ketiadaan Batang Galat (*Error Bars*):** R² sebesar $0{,}9997$ memberi ilusi "tanpa salah ukur", padahal hasil $g$ meleset $3{,}6\%$. Siswa olimpiade harus diajarkan bahwa $R^2$ tinggi tidak selalu berarti nilai akurasi parameter fisisnya tepat tanpa bias sistemik.

## 3 Masalah Paling Penting

### 1. Fallback Regresi Titik Tunggal Menghasilkan Nilai Nol dan Galat Semu 0.00%
- **Bukti Observasi:** Pada bukti `bandul_analysis_kembali`, saat data hanya berisi $n = 1$ ($L = 0{,}75$), sistem menampilkan: `Gradien (m): 0.0000 s²/m`, `g hitung: 0.0000 m/s²`, `Galat: 0.00%`.
- **Tingkat Keparahan:** **CRITICAL**
- **Rekomendasi Spesifik:** Berikan *guard condition* pada modul analisis: jika $n < 3$, jangan hitung regresi atau tampilkan $g = 0$. Blokir tampilan grafik regresi dengan pesan: *"Dibutuhkan minimal 3 titik data dengan variasi parameter berbeda untuk menghitung regresi linier."* Rumus galat juga harus mencegah pembagian bernilai nol.

### 2. Akurasi Penentuan Gravitasi Melebihi Toleransi Protokol (> 2%)
- **Bukti Observasi:** Pada bukti `analysis_dengan_data`, $5$ trial menghasilkan $g_{\text{hitung}} = 10{,}1598\text{ m/s}^2$ dengan $\text{Galat} = 3{,}60\%$. Protokol H2 mensyaratkan target galat $< 2\%$.
- **Tingkat Keparahan:** **HIGH**
- **Rekomendasi Spesifik:** Kalibrasi kembali pembangkitan periode $T$ pada engine simulasi (faktor *noise* 1,5% terlalu mendistorsi regresi pada bentang $L \le 1{,}0\text{ m}$) atau masukkan koreksi simpangan berhingga $\theta_0 = 10^\circ$ ke dalam persamaan reduksi data jika simulasi menggunakan persamaan diferensial non-linier ($\ddot{\theta} + \frac{g}{L}\sin\theta = 0$).

### 3. Teks Peringatan Tegangan Mati pada Millikan Tidak Muncul sebagai Feedback Eksplisit
- **Bukti Observasi:** Pada bukti `warning_tegangan_mati`, saat instrumen dimatikan (`Medan Listrik Pelat: OFF (Mati)`, `E = 0 (Jatuh Bebas)`), tidak tampak banner/dialog peringatan tegas bertuliskan *"Medan listrik belum aktif..."* saat tombol rekam ditekan; tampilan hanya mengandalkan label status kecil di inspeksi okular.
- **Tingkat Keparahan:** **MEDIUM**
- **Rekomendasi Spesifik:** Tampilkan notifikasi toast/modal peringatan yang mencegah perekaman data statis saat $V = 0\text{ V}$, disertai panduan: *"Tegangan pelat 0 V. Partikel sedang jatuh bebas murni, tidak dapat digunakan untuk mengukur gaya listrik."*
